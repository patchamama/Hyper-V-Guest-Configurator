Dedicated Seat

Assign a USB mouse and keyboard exclusively to a VM (RDP) or a kiosk browser. The devices leave Windows and only control the seat window; the rest of Windows keeps its own keyboard/mouse. Runs in WSL (Xorg + view-only VNC).

Requirements

Checking usbipd-win, WSL and Linux packages…
